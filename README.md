# MusicBand-Manager

Web app per gestire band musicali: membri, repertorio, prove, live e scalette, con un assistente AI locale (Ollama).

Progetto finale Fullstack (ITS FS25). Stack: React + Material UI, Laravel, MySQL, Docker, Ollama.
